Tools

SITool — Speech Intelligibility Toolkit for Subjective Evaluation

tool · example files

A Flask-based application for conducting standardized speech intelligibility tests (Diagnostic Rhyme Test, Modified Rhyme Test), with a Python script for analyzing results. Participants listen to audio samples, select answers, and submit responses for analysis.

bt4vt — Bias Tests for Voice Tech

tool · docs

A Python library to diagnose performance discrepancies (bias) in speaker verification models — evaluation measures and visualizations that can be integrated into development pipelines. Developed as part of the Fair EVA open-source project, with Wiebke Hutiri.
